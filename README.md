# Password Security Demo

An interactive, browser-based educational tool for exploring password security, password strength estimation, and common password weaknesses.

## Features

- Interactive password strength analysis
- Learn Mode and Attacker Mode
- Common password pattern detection
- Entropy calculations and comparisons
- Estimated password guessing difficulty
- Random password generation
- Passphrase generation
- SHA-256 hashing demonstration

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Web Crypto API

## Privacy

The application is designed to run entirely in the browser. Password input is processed locally and is not intentionally transmitted to a server.

**Use sample passwords only. Never enter actual account credentials.**

## Limitations

Password strength scores and estimated guessing difficulty are educational approximations, not guarantees or industry-standard security assessments.

The analysis primarily targets English-language passwords and may be less accurate for other languages.

## Deployment

This project can be hosted using GitHub Pages.

## Disclaimer

Educational demonstration only. This tool should not replace professional password security practices, password managers, or multi-factor authentication.
